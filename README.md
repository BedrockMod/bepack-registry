# bepack-registry

整合包来源登记与版本索引仓库。只保存索引与验证记录，不托管 .bepack、插件或游戏本体。当前仅完成本地仓库初始化，尚未部署同步器、通知服务或 catalog。

## 数据目录

- `sources/`：人工审核的包来源，一包一个文件，一仓库一个包 ID。
- `releases/`：可信验证器生成的不可变版本记录，不接受作者自报扫描通过。
- `withdrawals/`：追加的撤回、隔离或恢复状态，不覆盖原始资产摘要。
- `examples/`：仅供阅读的登记示例，绝不是已登记来源。

后续 `catalog` 分支发布 `registry.json` 和 `packs/<sha256>.json`。当前不生成假索引，不将同步失败回退为空列表。

## 收录链路

首次 PR 登记并审核来源控制证明；已登记来源的新 Release 由可信工具独立下载、校验和复核扫描后产生 Bot PR，通过门禁后更新索引。
`pack-released` 事件由官方通知 App/桥转发；作者工作流不持有官方写凭证。周期同步补偿漏事件。

详见 [收录指南](docs/收录指南.md) 和 [运维与撤回](docs/运维与撤回.md)。

## 当前限制

Schema、同步/验证/生成器、GitHub App、Actions、扫描凭证和真实端到端收录均未实现；不可作为生产索引源。仓库尚未确定开源许可，不作默认授权。
